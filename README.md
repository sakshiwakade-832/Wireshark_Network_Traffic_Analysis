# Wireshark_Network_Traffic_Analysis

## Project Overview 
This project focuses on analyzing network traffic using Wireshark in a controlled cybersecurity lab environment.

## Lab Environment

- Kali Linux
- Metasploitable 2
- Wireshark
- Nmap

## Objectives

- Capture network traffic
- Analyze ARP and ICMP packets
- Understand TCP communication
- Analyze HTTP and DNS traffic
- Study network conversations
- Analyze TCP streams
- Observe Nmap-generated traffic

## Network Analysis

### 1. ARP Analysis
Analyzed ARP request and reply packets address resolution.

### 2. ICMP Analysis
Captured ICMP echo request and echo reply packets generated during connectivity testing.

### 3. TCP Analysis
Analyzed TCP communication including SYN, SYN-ACK and ACK packets.

### 4. HTTP Analysis
Captured and analyzed HTTP traffic in the controlled lab environment.

### 5. DNS Analysis
Analyzed DNS queries and responses to understand domain-name resolution.

### 6. Nmap Traffic Analysis
Captured network traffic generated during an Nmap scan and examined the packets in Wireshark.

### 7. Conversations
Used Wireshark Conversations to examine different hosts and ports.

### 8. TCP Stream Analysis
Followed TCP streams to understand the complete communication between endpoints.

## Project Structure

-'PCAP/' - Packet capture files
-'Screenshots/' - Analysis screenshots
-'Report/' - Detailed project report

This project helped me understand how network communication appears at the packet level and strengthened my practical knowledge of network traffic analysis using Wireshark.
